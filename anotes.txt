Com Expo:

Iniciando o projeto com expo:
npx create-expo-app@latest

Iniciando o projeto com themas:
npx create-expo-app@latest my-app -t

Iniciando o app:
npm run android

Para buildar:
eas build -p android --profile preview


Trabalhando com navegação:
Cada um possui algumas deps, é bom ver a documentação para cada um, mas o básico é instalar o pacote principal e depois os stacks, tabs ou drawer dependendo do tipo de navegação que deseja usar.
npx expo install @react-navigation/native: https://reactnavigation.org/
npx expo install @react-navigation/native-stack
npx expo install @react-navigation/bottom-tabs
npx expo install @react-navigation/drawer
npx expo install expo-image-picker
//Adicione a permissão também no app.json para o expo-image-picker funcionar corretamente: https://docs.expo.dev/versions/latest/sdk/imagepicker/

Outras instalações (Expo):

npx expo install expo-notifications

// Para usar o firebase, é necessário instalar o pacote e depois personalizar o metro.config.js para que o firebase funcione corretamente com o Expo.
npx expo install firebase
npx expo customize metro.config.js
